Speed test, explained

Know what each number means.

What is download speed?

Download speed measures how quickly data comes to your device. Higher speeds help with streaming, downloads, and multiple connected devices.

What is upload speed?

Upload speed measures how quickly your device sends data, which matters for video calls, cloud backups, and sharing large files.

What is ping?

Ping is the round-trip time for a small request. Lower latency often feels more responsive in games and live conversations.

Why can results vary?

Wi-Fi signal, router load, network congestion, device activity, and the test server can all affect a result. Try a few tests at different times.
